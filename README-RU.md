# GamePlanet Тверь — демо для GitHub Pages

Готовый статический сайт: 11 товаров, корзина, избранное, личный кабинет и открытая админка с 12 учебными заказами. Вход через Telegram, сервер, база данных и платёжные ключи не требуются. Это отдельная копия: рабочий магазин на VPS не изменяется.

## Посмотреть локально

При установленном Node.js выполните в этой папке:

```sh
node serve.mjs
```

Откройте `http://127.0.0.1:3182/gameplanet-demo/`. Админка: `http://127.0.0.1:3182/gameplanet-demo/#/admin/orders`.

## Загрузить на GitHub Pages

1. Распакуйте архив. Загрузите его содержимое в корень отдельного репозитория: `index.html`, `app.js`, `app.css`, `.nojekyll` и папки `assets`, `fonts` обязательны. Не загружайте ZIP как единственный файл.
2. В репозитории откройте **Settings → Pages → Deploy from a branch**.
3. Выберите ветку `main`, папку `/ (root)` и сохраните.
4. Откройте выданную GitHub ссылку. Навигация через `#/…` работает и в подпапке репозитория, перезагрузка маршрутов не требует серверных правил.

Сборка уже включена. Для публикации установка npm не нужна. Имя репозитория может быть любым.

## Что можно показать клиенту

- Каталог с поиском, ценовыми фильтрами и категориями, карточки с фотографиями, избранное и корзина.
- Демонстрационное оформление заказа, имитация оплаты и история заказов. Реальные деньги не списываются, заявки магазину не отправляются.
- Админку: товары, предпросмотр и загрузку изображений, категории и подкатегории, несколько категорий у одного товара, флаг новинок, CSV-импорт.
- Обработку заказов: статусы, пример трек-номера, возвраты, склад, учебные расходы и финансы.
- Оформление магазина: логотип, баннер, цвета, заголовки, тексты и независимые переключатели двух надписей поверх фотографии. Выключение сохраняет текст надписи.

Изменения в админке сохраняются **только в браузере текущего посетителя** через IndexedDB (с резервным localStorage). Общей серверной админки у GitHub Pages нет. Кнопка «Сбросить демо» возвращает исходный пример с подтверждением. При недоступном хранилище сайт показывает предупреждение.

Для изменения исходного сайта для всех посетителей редактируйте `src/gameplanet.json`, `src/seed-products.json`, при необходимости `src/initial-state.mjs`, пересоберите и обновите файлы в репозитории. Существующее локальное демо посетителя обновится после сброса; для автоматического сброса версии меняйте `namespace` в `src/browser-api.ts`.

## Разработка

```sh
npm install
npm run build
npm test
```

React 19, esbuild, маршруты на hash. `build.mjs` создаёт `app.js`, `app.css` и копии используемых шрифтов. Серверы API не вызываются: `src/browser-api.ts` обрабатывает запросы локально. Демо не содержит ключей платёжных систем, Telegram-токенов или данных VPS.
